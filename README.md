## REACT PORTFOLIO by FUTURESKILL

#### Tools and Framwork

- Visual Studio Code
- Vite
- ReactJs
- react-icons/fa6
- react-type-animation
- react-parallax-tilt

#### How to install project

Open terminal and create vite use command

```bash
npm create vite@latest
```

Create folder name

```
folder-name
```

##### Select framwork
-- Select `React` framwork

##### Select variany
-- `Javascript`

##### Install with npm and start now
-- Select `Yes`

##### Open visual studio code
Create Components and create file

```bash
npm install react-icons/fa6
```

and 

```bash
npm install react-type-animation
```

and

```bash
npm install react-parallax-tilt
```

Go to App.jsx file and open terminal and run server in terminal
```
npm run dev
```
